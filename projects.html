Hardware and systems

  • Canada's first driverless formula car. UTFR, eight person team, 200+ hours of track testing. C++17 on Jetson ARM64, bare metal drivers for LiDAR, V4L2 camera and SPI IMU, SLAM fusing all three at 100Hz for 5cm localization at 100km/h. Control loop cut from 18ms to 8ms with PREEMPT_RT, lock free queues and thread pinning. ROS2 and Gazebo hardware in the loop.
  • Linux driver and firmware stack for an FPGA accelerator. C, Linux kernel character driver, MMIO and ioctl. Traced a hang down to a completion flag, which remains my favourite bug.
  • Neural network inference accelerator on FPGA. SystemVerilog, Python and embedded C on a DE10-Lite. Four hidden layer MLP at 95% MNIST accuracy. Q8.8 fixed point halved memory bandwidth. Verified in ModelSim against a Python reference.
  • Runtime layer for a RISC-V AI accelerator. C and C++, team of two. Operator dispatch, memory allocation, async queues, and a DMA style scheduler that cut transfers around 40%.
  • Cycle accurate AI accelerator simulator. C++ and Python. Discrete event scheduler tracking per cycle pipeline state across compute and memory for transformer inference.
  • GPU performance observability platform. Telemetry from distributed PyTorch training via Nsight Systems and NVML, automated bottleneck classification, Grafana over Prometheus.
  • Voice controlled racing game in assembly. Written for a DE1-SoC. Exactly as unreasonable as it sounds.
  • Electroverter. Converts road traffic noise into electricity for homes in low income neighbourhoods. Built at 11 with university professors and sold to a top Indian university.
